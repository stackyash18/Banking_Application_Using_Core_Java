# 🏦 Banking Application Using Core Java

A console-based **Banking Management System** developed using **Core Java** to demonstrate Object-Oriented Programming, interfaces, collections, layered architecture, exception handling, and other fundamental Java concepts.

The application allows users to perform basic banking operations such as creating accounts, depositing money, withdrawing money, and viewing account information through a command-line interface.

---

## 📌 Project Overview

The **Banking Application Using Core Java** is a compiler/console-based application designed to simulate basic banking operations.

The main objective of this project is to apply **Core Java concepts in a practical application** rather than building a simple collection of independent programs.

The project follows a simple **layered architecture**, separating application logic, business logic, domain models, and data storage.

---

## ✨ Features

### 👤 Account Management

- Create a new bank account
- Generate a unique account ID
- Store customer and account details
- View all registered accounts

### 💰 Banking Operations

- Deposit money into an account
- Withdraw money from an account
- Check account information
- Validate account existence before performing operations

### 🖥️ Console-Based Interface
